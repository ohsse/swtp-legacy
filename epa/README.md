
✨ 스마트 정수장 EMS 관망 해석 시뮬레이션 프로젝트
이 프로젝트는 스마트 정수장 EMS(Energy Management System)의 핵심 기능인 관망 해석 시뮬레이션을 위한 Python 기반의 솔루션입니다. EPANET 모델을 활용하여 실시간 데이터를 분석하고, 그 결과를 데이터베이스에 체계적으로 저장합니다.

📁 프로젝트 주요 파일
epanet_mo_loop.py:

기능: 5분마다 자동으로 실행되는 주기적 관망 해석 스크립트입니다.

동작 방식: TB_RAWDATA 테이블에서 현재 시점 직전의 최신 데이터를 가져와 EPANET 모델의 수요량으로 설정하고, 시뮬레이션을 실행합니다.

결과 저장: 해석 결과(압력, 유량, 수두손실)는 TB_FP_SI_VAL, TB_FR_SI_VAL, TB_TOT_ALG 테이블에 저장되며, FLG 필드에 'mo' 값을 기록하여 정기 모니터링 데이터임을 나타냅니다.

epanet_si.py:

기능: 특정 시점의 스냅샷 데이터를 기반으로 관망을 해석하는 스크립트입니다.

동작 방식: TB_EPA_SIM_RESV_FLOW 테이블에서 유량 데이터를 불러와 EPANET 모델의 수요량으로 설정합니다. 필요에 따라 변경된 INP 파일을 지정된 경로에 저장할 수 있습니다.

결과 저장: epanet_mo_loop.py와 동일한 테이블에 결과를 저장하지만, FLG 필드에 'si' 값을 기록하여 단발성(Snapshot) 시뮬레이션 데이터임을 구분합니다.

gs_inp.inp:

기능: EPANET 시뮬레이션의 기본 모델 역할을 하는 입력 파일입니다.

내용: 관망 네트워크의 노드([JUNCTIONS]), 펌프([PUMPS]), 밸브([VALVES]), 파이프([PIPES]) 등 물리적 요소들의 정보를 정의하고 있습니다. 또한, EPANET 시뮬레이션의 동작 방식을 제어하는 규칙([RULES])과 에너지 손실 계산 설정([ENERGY])도 포함되어 있습니다.

connections.json:

기능: 프로젝트에서 사용하는 데이터베이스 접속 정보를 관리하는 파일입니다.

내용: 여러 환경(예: maria-ems-db-gs, maria-ems-db-gm)에 대한 데이터베이스 호스트, 포트, 사용자, 비밀번호, 데이터베이스 이름 등을 JSON 형식으로 정의합니다. 각 스크립트는 이 파일을 참조하여 필요한 데이터베이스에 연결합니다.

🚀 시스템 분석 및 활용
이 시스템은 스마트 정수장 EMS가 관망 상태를 효과적으로 관리하고 분석하는 데 필수적인 정보를 제공합니다.

실시간 모니터링 (epanet_mo_loop.py): 5분 단위로 자동으로 실행되어 관망의 현재 상태를 지속적으로 모니터링하고 예측합니다. 이는 관망의 잠재적인 문제를 조기에 발견하는 데 도움이 됩니다.

맞춤형 분석 (epanet_si.py): 특정 상황(예: 펌프 작동 방식 변경, 특정 지점의 유량 변화)에 대한 영향을 분석하기 위해 수동으로 시뮬레이션을 실행할 수 있습니다. 이를 통해 다양한 운영 시나리오를 검토하고 최적의 대응 방안을 모색할 수 있습니다.

데이터 기반 의사결정: 시뮬레이션으로 생성된 분석값과 실제 측정값을 함께 데이터베이스에 저장하여, 시스템의 예측 정확도를 검증하고 더 나은 의사결정을 위한 기반을 마련합니다.

이 프로젝트는 코드의 모듈화와 유연한 설정(connections.json 파일)을 통해 다양한 환경에 쉽게 적용하고 확장할 수 있도록 설계되었습니다.
